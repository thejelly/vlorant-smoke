# 无畏契约 · 烟雾点位指南

一个纯静态的网页,用于查看《无畏契约》(VALORANT)各地图在**进攻方**与**防守方**下的常用烟雾(下烟)点位。

## 功能

- **地图切换**:内置 11 张地图(亚海悬城、隐世修所、森寒渡口、裂变峡谷、森罗监狱、微风岛屿、裂痕、深海明珠、莲华古城、日落之城、深渊之城)。
- **阵营切换**:一键在「进攻方 / 防守方」之间切换,分别展示各自常用点位。
- **示意图定位**:每个点位在抽象布局示意图上以编号标记显示,点击标记或列表项可高亮联动。
- **点位说明**:每个点位包含名称、所属区域(A / B / C / 中路)以及下烟作用说明。
- **响应式布局**:适配桌面与移动端。

## 使用方法

直接用浏览器打开 `index.html` 即可,无需任何构建或依赖。

也可部署到 GitHub Pages:仓库设置 → Pages → 选择分支根目录即可访问。

## 项目结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 样式 |
| `app.js` | 交互逻辑(地图/阵营切换、标记联动) |
| `data.js` | 点位数据(按地图与阵营组织,便于扩展) |

## 扩展点位数据

编辑 `data.js`,在对应地图的 `attack` 或 `defense` 数组中新增对象即可:

```js
{
  id: "唯一ID",
  name: "点位名称",
  area: "区域(A 点 / B 点 / 中路 ...)",
  purpose: "下烟作用说明",
  x: 70,  // 示意图横向位置(0-100 百分比)
  y: 30,  // 示意图纵向位置(0-100 百分比,上=A 侧 下=B/C 侧)
}
```

## 说明

点位数据为常见通用示意,仅供参考学习。VALORANT 为 Riot Games 商标,本页面与其无官方关联。
